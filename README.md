# 日本語辭典 使用說明

一個陪你學日文的網站：輸入任何語言就能查到日文，還有五十音表、小考、每日學習目標，以及一隻會陪讀的貓咪或小狗。

網站分成六個分頁：**查詞、單字庫、五十音、小考、進度、單字本**。電腦寬螢幕時，左右兩側還有「今日學習」「日語小知識」「隨機單字」「小考最高分」等小卡片。

---

## 1. 查詞

1. 在輸入框輸入想查的詞或句子，語言不限，中文、英文、韓文、西班牙文，或日文本身都可以，然後按「查詢」或 Enter。
2. 最多會顯示 3 個最貼切的日文詞條，每個詞條包含：
   - 日文寫法、平假名讀音、羅馬拼音
   - 詞性與 JLPT 等級
   - 中文釋義，以及詞義、語感、使用場合的說明
   - 2 個附讀音與翻譯的例句
   - 相關詞（點一下就能接著查）
3. 按 🔊 可以聽日文發音，例句旁邊也有 🔊。
4. 按「＋單字本」把單字收進單字本，同時會算進今天的學習進度。
5. 輸入句子時，會給出完整的日文翻譯，並解說文法與用詞。

查詞頁最上方的「**今日の言葉**」每天會換一個日文單字，可以聽發音，也可以點「查看詳解」。

## 2. 單字庫（N5～N1）

- 上方選擇 N5、N4、N3、N2、N1，會列出該等級的內建單字，每級 20 個。
- 每個單字可以按 🔊 聽發音，按 ＋ 收進單字本（已收藏的會顯示 ✓）。
- 按「用 Nx 開始小考」會直接帶著該等級跳到小考頁。

## 隨機單字

- 電腦版的右側（手機版在查詞頁上方）有「🎲 隨機單字」卡片。
- 可以選「全部」或指定某個等級，按「換一個」就會隨機出現新單字，也能聽發音或直接加入單字本。

## 3. 五十音

- 上方可以切換 **平假名 / 片假名**，以及 **清音 / 濁音・半濁音**。
- 點任何一個字，上方會顯示放大的字和羅馬拼音，同時播放發音。
- 建議先用這個頁面熟悉字形和讀音，再去小考測試。

## 4. 小考

每次 10 題，選擇你要的類型：

| 類型 | 說明 |
| --- | --- |
| 詞彙測驗 | 先選單字庫等級（N5～N1），再選難度 |
| 　簡單（15 秒） | 題目附讀音，看日文選中文意思 |
| 　普通（10 秒） | 不附讀音，看日文選中文意思 |
| 　困難（8 秒） | 看中文選出正確的日文 |
| 平假名 / 片假名 | 看字選出正確的羅馬拼音 |
| 聽音辨字 | 聽發音，選出正確的假名 |
| 單字本測驗 | 用你自己收藏的單字出題，單字本至少要有 4 個單字 |

- **每題都有時間限制**：頂端有倒數計時條，最後 3 秒會變紅色。時間到沒作答，會算答錯，並顯示正確答案。
- 答對會顯示綠色，答錯會顯示紅色並標出正確答案。
- 結束後會顯示分數，高分還會有彩帶慶祝。每種小考都會記錄你的最高分。
- 結算畫面下方有**錯誤解析**：列出每一題答錯的題目、你選的答案其實是什麼、正確答案是什麼（超時未答的題目也會列出）。詞彙測驗答錯的單字，可以直接按「＋單字本」收藏起來複習。
- 中途想離開，可以按「結束小考」。

## 5. 進度（學習目標）

1. 選擇目標等級（N5、N4、N3、N2、N1），或選「自訂字數」自己填目標單字數。各等級的字數是常見的參考值。
2. 設定完成日期，按「儲存目標」。
3. 系統會依「剩餘單字數 ÷ 剩餘天數」自動算出**每日要學幾個字**。
4. 進度頁會顯示：
   - 今日進度環：今天已學幾個字 / 每日目標
   - 總進度條：累計單字數 / 目標單字數
   - 連續學習天數、距離完成日的天數
   - 已記住的單字數、今日複習張數、小考完成次數與最高分
   - 最近 7 天的學習柱狀圖
5. 每把一個新單字加入單字本，就算今天學了 1 個字。頁面右上角的小標籤也會即時顯示「今日 x / y 字」。

## 6. 單字本

- 這裡列出你收藏的所有單字，可以按 🔊 聽發音。
- 按 ☐ 把單字標記為「已記住」（✅），按 ✕ 刪除單字。
- **開始複習**：會出現單字卡，先想一下意思，再按「顯示答案」。
  - 按「記得」：該單字的熟悉度加一，連續答對 3 次會自動標為已記住。
  - 按「還不熟」：熟悉度歸零，之後會再出現。
  - 每次最多複習 20 張，優先出現最久沒複習的單字。

## 7. 陪讀夥伴

- 畫面下方有一隻可愛的小貓咪（或小狗）會走來走去，會陪你一起學習：切換分頁時會打招呼，答對會跳起來，答錯會安慰你。
- 點一下牠，牠會停下來回應你。
- 左下角的選擇列可以更換夥伴：
  - 🐱 貓咪：橘貓、黑貓、白貓、灰貓
  - 🐶 小狗：柴犬、黑狗、白狗、灰狗
- 你的選擇會被記住，下次開啟還是同一隻。

## 建議的學習流程

1. 先到「五十音」熟悉平假名和片假名，再到「小考」用五十音測驗檢查自己。
2. 到「進度」設定目標，算出每日單字量。
3. 每天用「查詞」或「單字庫」找新單字，加入單字本，達到每日目標。
4. 用「單字本」複習，再到「小考」做詞彙測驗，看錯誤解析補強弱點。
5. 難度從簡單開始，穩定拿到高分後再挑戰普通和困難。

## 注意事項

- **資料存在你自己的瀏覽器裡**：單字本、學習進度、最高分和夥伴設定都儲存在目前使用的瀏覽器。換電腦、換手機，或清除瀏覽器資料後，這些紀錄不會同步，也可能消失。
- **要連上網路才能查詞**：查詞內容是 AI 即時生成的，偶爾可能有誤，重要的用法建議再對照正式辭典。
- **內建的單字庫（每級 20 個）與 JLPT 等級只是大致的分級參考**，不等於正式考試範圍。
- **發音使用瀏覽器內建的語音**：不同裝置的聲音可能不同，若沒有聲音，請確認裝置有安裝日文語音，且沒有靜音。
